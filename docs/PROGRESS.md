## Phase 0: 개발 환경 구성과 기본 서버 연결

### 완료한 기능

| 영역 | 구현 내용 | 관련 파일 |
| --- | --- | --- |
| 프론트엔드 | React + Vite 실행 환경, 개발 포트 5173 고정 | `frontend/package.json`, `package-lock.json`, `vite.config.js`, `index.html`, `src/main.jsx` |
| 스타일 | Tailwind CSS Vite 플러그인과 기본 스타일 | `frontend/vite.config.js`, `src/index.css`, `src/App.jsx` |
| 연결 화면 | EXCUSE ME! 제목, 서버 연결 버튼, 정상 JSON 표시, 연결 실패 안내 | `frontend/src/App.jsx` |
| 서버 주소 | 기본 주소 `http://127.0.0.1:8000`, 비밀값 없는 환경변수 예시 | `frontend/src/App.jsx`, `.env.example` |
| 백엔드 | Python 가상환경 `.venv`, FastAPI + Uvicorn, 의존성 버전 기록 | `backend/main.py`, `requirements.txt`, `requirements.lock.txt` |
| API | `GET /api/health` → HTTP 200, `{"status":"ok"}` | `backend/main.py` |
| CORS | `http://localhost:5173` 및 `http://127.0.0.1:5173`의 GET 요청 허용 | `backend/main.py` |
| SQLite | Python 가상환경에서 메모리 연결 및 조회 가능 여부 확인 | 실제 DB 파일 및 작품·투표 테이블 생성 없음 |
| 실행 안내 | Windows PowerShell 설치·실행·종료·재실행 명령 | `README.md` |

`database/`는 향후 저장용 빈 폴더이며 실제 DB 파일 위치·구조·생성 방식은 후속 DB 구현 때 구체화합니다. Phase 0에서는 저장 기능을 만들지 않았습니다. 빈 폴더 자체는 Git에 저장되지 않습니다.

### 사용자 브라우저 직접 테스트

2026-10-30 사용자가 다음 결과를 전달했습니다.

| 검사 | 사용자 확인 결과 |
| --- | --- |
| React 웹페이지 열기 | 정상 표시 |
| Tailwind CSS | 스타일 정상 적용 |
| 서버 연결 확인 버튼 | 연결 성공 및 `{"status":"ok"}` 응답 표시 |
| 백엔드 종료 후 같은 버튼 클릭 | 연결 실패 안내 표시 |
| 백엔드 재실행 후 연결 확인 | 연결 성공 상태로 복구 |

개발 당시 브라우저 자동화가 중단되어 남겨 두었던 필수 화면 검증을 사용자 직접 테스트로 확인했습니다. 자동화 도구로 검증했다고 기록하지 않습니다.

### 별도 테스트하지 않은 항목

- 5초 시간 초과 분기.
- 비정상 HTTP 상태, 잘못된 JSON, 예상과 다른 JSON 형식의 화면 안내.
- 요청 중 버튼 비활성화 및 오류 후 이전 응답 제거의 개별 동작.

위 항목은 구현되어 있으나 개별 테스트를 통과한 것으로 기록하지 않습니다. Phase 0의 필수 정상 연결·서버 중단·복구 테스트와 구분합니다.

### Git 저장 범위와 제외 항목

저장 대상은 Phase 0의 프론트엔드·백엔드 코드 및 설정, 패키지 잠금 파일, 비밀값 없는 `.env.example`, `README.md`, 이 진행 기록입니다.

기존 `.gitignore` 규칙을 유지하며 실제 `.env`, 비밀값, `.venv`, `node_modules`, 캐시, 로그, 빌드 결과 및 SQLite DB 파일을 커밋 대상에서 제외합니다. 기존 MVP·PRD·SPEC·PLAN은 수정하지 않습니다. 다른 작업의 변경사항을 임의로 포함하지 않습니다.

## 다음 Phase

**Phase 1: 박물관 랜딩페이지와 전시관 기본 UI**를 진행합니다.

- 착수 전 화면 주소·이동 구조와 랜딩페이지 예시를 고정 문구로 둘지 실제 작품 조회로 할지 확인합니다.
- 랜딩페이지, 상설 전시관, 감상실, 기증, 명예의 전당의 화면 구조와 기본 이동 틀을 구성합니다.
- 기존 기획 문서의 용어를 적용하고 좁은 화면에서도 주요 글·버튼이 잘리지 않게 합니다.
- 개발용 예시를 실제 저장 결과로 표시하지 않고 미연결 기능을 구분합니다.
- Phase 0 서버 연결을 유지합니다. 작품·투표 저장 기능과 실제 기능 API는 해당 후속 Phase에서 구현합니다.

Phase 1 코드는 이번 완료 처리 작업에 포함하지 않습니다.
