## Phase 1: 랜딩페이지와 상설 전시관 기본 UI

### 구현 상태

- `/`: 기존 EXCUSE ME! 랜딩페이지, 소개·전시 관람하기 링크·기증 준비 중 안내·대표 샘플 미리보기.
- `/gallery`: 디자인 확인용 샘플 작품 8개, 작품 번호·제목·본문 미리보기·가상 작가·카테고리·가상 명작 인정 수.
- 전체·지각·과제·약속·운동·기타 샘플 필터와 샘플 최신순·인기순 정렬. 실제 DB 조회나 실제 투표 기능이 아님.
- `/submit`, `/artworks/:id`, `/hall-of-fame`: 실제 기능 대신 준비 중 안내. 버튼은 네이티브 dialog를 여는 코드가 있음.
- `/health`: Phase 0 연결 확인 화면. 백엔드 `GET /api/health`와 기존 요청·오류 처리 유지.
- 메인 배경 #F9FAFB·텍스트 #24201F·버건디 #A32632, 현재 히어로·액자·카드·버튼·레이아웃을 유지. 이번 저장 작업에서 React 코드와 디자인을 수정하지 않음.

### 실제 브라우저에서 직접 확인하지 못한 항목

브라우저 자동화 도구가 Windows에서 현재 URL을 확인하지 못해 중단되었습니다. 따라서 다음 항목은 성공으로 기록하지 않습니다.

- /와 /gallery의 실제 표시·글꼴·색상·잘림 여부, 데스크톱/모바일 배치.
- 전시 관람하기 클릭으로 /gallery 이동, 뒤로가기 및 직접 새로고침.
- 각 카테고리 버튼 클릭으로 카드 변경·선택 표시·전체 복귀.
- 샘플 정렬 선택과 카드 순서 변경.
- 기증·작품 카드·명예의 전당 클릭으로 준비 중 dialog 열기·확인·Escape 닫기.
- /health의 연결 성공·실패·복구를 새 화면에서 버튼으로 확인.

Phase 0 당시의 사용자 직접 테스트 통과는 위 Phase 0 절의 기록대로 유지합니다. Phase 1 UI 전체의 직접 테스트가 새로 완료된 것은 아닙니다.
