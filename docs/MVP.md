# EXCUSE ME! MVP

## 1. 서비스와 첫 버전의 목표

EXCUSE ME!는 일상 속 황당하고 창의적인 핑계를 예술 작품처럼 등록하고 감상하는 참여형 디지털 박물관입니다.

주요 사용자는 짧고 재미있는 콘텐츠를 즐기고 자신의 경험을 재치 있게 공유하고 싶은 LG AX 1기 부트캠프 사람들입니다.

MVP는 서비스의 핵심 경험을 확인하기 위해 꼭 필요한 기능만 갖춘 첫 번째 버전입니다. 코딩 초보자가 1~2주 안에 만들 수 있도록 텍스트 작품의 기증, 감상, 투표에 집중합니다.

| 일반적인 게시판 표현 | 서비스에서 사용하는 표현 |
| --- | --- |
| 게시글 작성 | 작품 기증 |
| 게시글 목록 | 상설 전시관 |
| 게시글 상세 | 작품 감상실 |
| 좋아요 | 명작 인정 |
| 인기 게시글 | 명예의 전당 |

개발에 사용할 기술은 React, Tailwind CSS, Python FastAPI이며, 초기 데이터 저장에는 SQLite를 사용합니다. 이 문서는 기능 범위와 완료 기준을 정하며, 코드 작성과 패키지 설치는 포함하지 않습니다.

## 2. 작품과 방문객의 기본 규칙

### 작품 정보와 카테고리

- 작품을 기증할 때 제목, 핑계 내용, 카테고리 한 가지를 입력합니다.
- 제목과 내용은 공백만 입력할 수 없습니다.
- 카테고리는 **지각, 과제, 약속, 운동, 기타** 다섯 가지로 제한합니다.
- 작품 번호, 등록 시각, 기증한 방문객 ID는 서비스가 자동으로 기록합니다.
- 명작 인정 수는 해당 작품에 남아 있는 투표의 개수입니다.
- 첫 버전의 작품은 텍스트로만 구성합니다.

### 브라우저별 데모 방문객 ID

- 정식 회원가입과 로그인은 제공하지 않습니다.
- 처음 방문할 때 임의의 데모 방문객 ID를 만들고 브라우저에 저장합니다.
- 같은 브라우저의 저장 정보가 유지되면 새로고침하거나 다시 방문해도 같은 ID를 사용합니다.
- 이 ID를 기준으로 본인 작품과 투표 여부를 구분합니다.
- 다른 브라우저나 기기를 사용하면 별도의 방문객으로 취급합니다. 같은 브라우저를 함께 쓰면 같은 방문객으로 취급될 수 있습니다.
- 브라우저 저장 정보를 삭제하거나 시크릿 창을 이용하면 기존 ID를 계속 사용할 수 없습니다. 기존 작품은 남아 있어도 본인 작품으로 수정하거나 삭제할 수 없게 될 수 있습니다. 첫 버전에는 ID 복구 기능이 없습니다.

**한계:** 데모 방문객 ID는 실제 사용자 인증을 대신할 수 없습니다. 브라우저에 저장된 ID는 사용자가 변경하거나 복사할 수 있어 다른 사람을 흉내 내거나 여러 ID로 투표할 수 있습니다. 따라서 본인 작품 구분과 중복 투표 제한은 데모 수준이며, 실제 사람 한 명당 한 표를 보장하지 않습니다. 공개 서비스로 확장할 때는 정식 인증과 권한 확인이 필요합니다.

## 3. 필수 기능과 완료 기준

### 1. 박물관 랜딩페이지

**필요한 이유**

처음 방문한 사람이 서비스의 주제와 참여 방법을 빠르게 이해하고 전시관으로 들어갈 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- EXCUSE ME!의 소개와 핑계 작품 예시를 읽습니다.
- 상설 전시관, 작품 기증, 명예의 전당으로 이동합니다.
- 랜덤 작품 감상을 시작합니다.

**완료 기준**

- 서비스 이름, 짧은 소개, 회원가입 없이 참여하는 데모라는 안내가 보입니다.
- 각 이동 버튼을 누르면 해당 화면이나 기능으로 연결됩니다.
- 휴대전화와 PC에서 주요 글과 버튼이 잘리지 않고 보입니다.

### 2. 핑계 작품 등록 — 작품 기증

**필요한 이유**

방문객의 경험이 새로운 전시 작품이 되어야 박물관의 콘텐츠가 쌓입니다.

**사용자가 할 수 있는 행동**

- 제목과 핑계 내용을 작성하고 카테고리를 선택합니다.
- 작품 기증 버튼을 눌러 등록합니다.
- 입력이 잘못되거나 등록에 실패하면 안내를 확인하고 다시 시도합니다.

**완료 기준**

- 제목, 내용, 카테고리가 모두 올바를 때만 등록됩니다.
- 비어 있거나 공백뿐인 제목·내용, 정해진 다섯 가지 외의 카테고리는 등록되지 않고 이유가 표시됩니다.
- 등록된 작품에 현재 방문객 ID가 연결됩니다.
- 등록 성공 후 새 작품의 감상실로 이동하고, 상설 전시관에서도 확인할 수 있습니다.
- 새로고침해도 등록한 작품이 남아 있습니다.

### 3. 작품 목록 및 상세 조회 — 상설 전시관과 작품 감상실

**필요한 이유**

여러 작품을 쉽게 둘러보고 마음에 드는 작품의 전체 내용을 읽을 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 상설 전시관에서 작품 목록을 봅니다.
- 작품을 선택해 감상실로 이동합니다.
- 감상 후 목록으로 돌아갑니다.

**완료 기준**

- 목록은 최근에 등록된 작품부터 보여줍니다.
- 목록에서 작품 제목, 카테고리, 명작 인정 수를 확인할 수 있습니다.
- 감상실에서 작품 번호, 제목, 전체 내용, 카테고리, 등록 시각, 명작 인정 수를 확인할 수 있습니다.
- 작품이 없으면 아직 기증된 작품이 없다는 안내와 작품 기증 버튼이 보입니다.
- 존재하지 않거나 삭제된 작품의 주소에 접속하면 안내와 전시관으로 돌아가는 버튼이 보입니다.

### 4. 카테고리별 필터링

**필요한 이유**

방문객이 관심 있는 상황의 핑계를 빠르게 찾아볼 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 상설 전시관에서 전체, 지각, 과제, 약속, 운동, 기타 중 하나를 선택합니다.
- 전체를 선택해 모든 작품을 다시 봅니다.

**완료 기준**

- 처음에는 전체 작품이 보입니다.
- 카테고리를 선택하면 해당 카테고리의 작품만 보이며, 최근 등록순을 유지합니다.
- 현재 선택한 항목을 화면에서 구분할 수 있습니다.
- 해당 카테고리의 작품이 없으면 결과가 없다는 안내가 보입니다.

### 5. 본인 작품 수정 및 삭제

**필요한 이유**

기증자가 오타를 고치거나 더 이상 공개하고 싶지 않은 작품을 내릴 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 본인 작품의 감상실에서 수정 또는 삭제를 선택합니다.
- 제목, 내용, 카테고리를 수정해 저장합니다.
- 삭제 확인 안내에서 삭제를 진행하거나 취소합니다.

**완료 기준**

- 작품에 기록된 방문객 ID와 현재 방문객 ID가 같을 때만 수정·삭제 버튼이 보입니다.
- 서버에서도 두 ID를 비교하며, 일치하지 않는 ID로 보낸 수정·삭제 요청은 거절합니다. 단, 이 비교는 앞서 설명한 데모 ID의 한계를 가집니다.
- 수정에도 작품 등록과 같은 입력 규칙을 적용합니다.
- 수정한 내용은 새로고침 후에도 유지되며, 기존 명작 인정 수는 유지됩니다.
- 삭제를 취소하면 작품이 그대로 남습니다.
- 삭제를 확정하면 작품과 연결된 투표가 제거되고, 목록·상세·명예의 전당·랜덤 감상에서 더 이상 나타나지 않습니다.
- 첫 버전에는 삭제한 작품을 복구하는 기능이 없습니다.

### 6. 작품별 명작 인정 투표 및 취소

**필요한 이유**

방문객이 공감을 간단하게 표현하고, 인기 작품을 정할 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 작품 감상실에서 명작 인정 버튼을 눌러 투표합니다.
- 이미 투표한 버튼을 다시 눌러 투표를 취소합니다.
- 현재 투표 수와 본인의 투표 여부를 확인합니다.

**완료 기준**

- 하나의 방문객 ID는 작품 하나에 한 표만 유지할 수 있습니다.
- 투표하면 수가 1 증가하고, 취소하면 1 감소합니다.
- 버튼을 빠르게 여러 번 눌러도 같은 방문객의 표가 중복 저장되거나 투표 수가 음수가 되지 않습니다.
- 새로고침해도 투표 수와 해당 방문객의 투표 여부가 유지됩니다.
- 투표 또는 취소 후 목록과 명예의 전당을 다시 조회하면 변경된 수가 반영됩니다.

### 7. 투표 수 기반 명예의 전당 TOP 10

**필요한 이유**

공감을 많이 받은 작품을 모아 보여주어 처음 방문한 사람도 인기 작품을 쉽게 발견할 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 명예의 전당에서 상위 작품의 순위와 명작 인정 수를 확인합니다.
- 작품을 선택해 감상실로 이동합니다.

**완료 기준**

- 현재 명작 인정 수가 많은 순서로 최대 10개 작품이 보입니다.
- 투표 수가 같으면 등록 시각이 최근인 작품을 먼저 보여주며, 등록 시각도 같으면 작품 번호가 큰 작품을 먼저 보여줍니다.
- 작품이 10개보다 적으면 있는 작품만 표시하고, 작품이 없으면 안내 문구가 보입니다.
- 투표, 투표 취소, 작품 삭제 후 다시 조회하면 순위가 갱신됩니다.
- 별도의 운영자 선정이나 수동 등록 없이 투표 수로 순위를 정합니다.

### 8. 랜덤 작품 감상

**필요한 이유**

방문객이 작품을 직접 고르지 않아도 우연히 재미있는 작품을 만날 수 있어야 합니다.

**사용자가 할 수 있는 행동**

- 랜딩페이지에서 랜덤 작품 감상을 누릅니다.
- 작품 감상실에서 다시 랜덤 감상을 눌러 다른 작품을 찾아봅니다.

**완료 기준**

- 삭제되지 않은 전체 작품 중 하나를 무작위로 골라 감상실로 이동합니다.
- 작품이 여러 개일 때 항상 같은 작품으로 고정되지 않습니다. 무작위 선택이므로 같은 작품이 연속으로 나올 수 있습니다.
- 작품이 하나뿐이면 해당 작품을 보여줍니다.
- 작품이 없으면 안내와 작품 기증 버튼을 보여줍니다.
- 개인 취향 분석이나 추천 알고리즘은 구현하지 않습니다.

## 4. 주요 이용 흐름

1. 랜딩페이지에서 서비스 소개를 읽고 상설 전시관에 입장합니다.
2. 전체 작품을 보거나 관심 있는 카테고리로 좁혀 봅니다.
3. 작품 감상실에서 내용을 읽고 명작 인정을 누릅니다.
4. 명예의 전당이나 랜덤 감상으로 다음 작품을 발견합니다.
5. 자신의 경험을 작품으로 기증합니다.
6. 같은 방문객 ID로 본인 작품을 수정하거나 삭제합니다.

## 5. 첫 MVP에서 제외하는 기능

- 댓글과 답글
- 이미지 업로드와 이미지 작품
- AI 핑계 생성
- 정식 회원가입과 로그인

범위가 커지지 않도록 검색, 알림, 팔로우, 개인별 추천, 별도의 관리자 화면도 첫 버전에는 포함하지 않습니다. 목록의 복잡한 정렬 옵션과 무한 스크롤도 후순위로 둡니다.

## 6. 전체 MVP의 최종 확인 기준

- 위 8가지 필수 기능의 완료 기준을 모두 확인합니다.
- 브라우저 A에서 기증한 작품을 브라우저 B에서도 감상할 수 있고, 각 브라우저는 서로 다른 방문객으로 구분됩니다.
- 브라우저 B는 일반적인 이용 흐름에서 A의 작품을 수정하거나 삭제할 수 없으며, 두 방문객의 투표 여부도 따로 유지됩니다.
- 작품 등록·수정·삭제와 투표·취소 결과가 새로고침 후에도 유지됩니다.
- 화면을 불러오는 중임을 알 수 있고, 저장이나 조회에 실패하면 이해할 수 있는 안내를 표시합니다. 저장에 실패한 작업을 성공했다고 표시하지 않습니다.
- 휴대전화와 PC에서 작품 기증부터 감상과 투표까지 핵심 흐름을 사용할 수 있습니다.
- 데모 방문객 ID가 실제 인증이 아니며, 브라우저 저장 정보 삭제 시 본인 작품 관리 권한을 잃을 수 있다는 안내를 사용자가 볼 수 있습니다.
